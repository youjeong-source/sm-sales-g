기존 UI vs 신규 데모 비교

기존 인터페이스 현재

  • 편집 모드 토글 (수정 → 입력 → 저장)
  • 입력 필드 작음 (폰트 13px), 우측 정렬
  • 합계 행 폰트 작음, 같은 톤 (회색)
  • 이익률 셀 작은 배지로만 표시
  • 카테고리 6개 가로 좁은 행
  • 실시간 갱신 (input 이벤트) ✓

신규 데모 인터페이스 제안

  • 인라인 편집 - 모드 전환 없이 클릭 즉시 편집
  • 큰 입력 필드 (폰트 16px, 패딩 넉넉)
  • 다크 합계 행 - 검정 배경 + 골드/오렌지 강조
  • 이익률 큰 글씨로 색상 강조 (good/warn/bad)
  • 상단 4-숫자 요약 박스 (매출/지출/순매출/이익률)
  • 카테고리 옆 이모지 아이콘으로 빠른 식별
  • 자동 저장 시 우측 상단 ✓ 토스트 (1.8s)
  • 포커스 시 빨간 테두리 + glow 효과
